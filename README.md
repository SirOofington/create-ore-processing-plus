# Create: Ore Processing Plus

Adds multiple ore processing lines, allowing you to multiply ore output up to **10x** more if fully optimized.

## Main Processing Recipes
### Tier 4 Processing (4x Ore)
1. **Mixing:** Lava (*1000mb*) + Powdered Obsidian (*4x*) + Superheated Blaze Burner = **Superheated Lava** (*250mb*)
2. **Compacting:** Raw Ore + Superheated Lava = **Dirty Ore Slurry**
3. **Mixing:** Dirty Ore Slurry + Water = **Clean Ore Slurry**
4. **Mixing:** Clean Ore Slurry (*250mb*) + Sand + Heated Blaze Burner = **Ore Crystal** [***continue or go to Tier 4 Bonus instead***]
5. **Crushing:** Ore Crystal = **Ore Fragment** (*4x + 5% chance of +1*)
6. **Crafting/Compacting:** Ore Fragment (*4x*) = **Ore Shard**
7. **Continue to Tier 3, Step 2**

#### Tier 4 Bonus (1.25x Ore)
1. **Mechanical Saw x8:** Ore Crystal = **Ore Fragment** (*5x*)
2. **Crafting/Compacting:** Ore Fragment (*4x*) = **Ore Shard**
3. **Continue to Tier 3, Step 2**

### Tier 3 Processing (3x Ore)
1. **Sequenced Recipe:** Raw Ore -> Spout Water -> Mechanical Press -> Mechanical Saw = **Ore Shard** (*3x*)
2. **Crushing:** Ore Shard = **Powdered Ore** [***continue or go to Tier 3 Bonus***]
3. **Mixing:** Powdered Ore + Lava (*250mb*) + Heated Blaze Burner = **Ore Flakes** (*9x*)
4. **Crafting/Compacting:** Ore Flakes (*9x*) = **Crushed Ore**
5. **Continue to either Tier 2 Bonus, or Tier 1)**

#### Tier 3 Bonus (1.33x Ore)
1. **Mixing:** Powdered Ore + Lava (*500mb*) + Superheated Blaze Burner = **Ore Flakes** (*12x*)
2. **Crafting/Compacting:** Ore Flakes (*9x*) = **Crushed Ore**
3. **Continue to either Tier 2 Bonus, or Tier 1)**

### Tier 2 Processing (2x Ore)
1. **Crafting/Compacting:** Raw Ore (*9x*) = **Raw Ore Block**
2. **Compacting:** Raw Ore Block + Lava (*250mb*) + Superheated Blaze Burner = **Crushed Ore** (*18x*)
3. **Continue to either Tier 2 Bonus, or Tier 1)**

#### Tier 2 Bonus (1.5x Ore)
1. **Compacting:** Crushed Ore (*2x*) + Lava (*250mb*) + Superheated Blaze Burner = **Ore Nuggets** (*27x*)
2. **Continue to Tier 1**

### Tier 1 (1x Ore)
Smelt, wash, or blast your raw/crushed ore.

## Misc. Processing Recipes

### Redstone/Lapis/Emeralds
Ore -> Compact Molten Ore -> Mix Ore Crystal -> Crush = ~2.5x Ore

### Netherite
**Compacting:** Golden Slurry (*1000mb*) + Netherite Scrap (*4x*) + Superheated Blaze Burner = **Netherite Ingot** (*3x*)
